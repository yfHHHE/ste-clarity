# Contributing

Keep the skill focused on clarity that preserves meaning. Prefer narrow corrections supported by a realistic example over new universal rules.

1. Describe the original ambiguity or failure and the intended behavior.
2. Update the canonical skill or its relevant reference. Keep source and rewrite examples faithful.
3. Synchronize the full Cursor mirror.
4. Run `python3 scripts/check_package.py` and `git diff --check`.
5. Report relevant behavioral evaluation outcomes and any untested runtime claims.

Use synthetic content. Do not submit credentials, personal data, private project details, or copyrighted standard text. Keep new dependencies and platform adapters proportional to the task.

Contributions are made under the repository's MIT license.
