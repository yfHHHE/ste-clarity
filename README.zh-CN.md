# STE Clarity

[English](README.md) | 简体中文

**让技术表达更清楚，同时保留原意。**

这是一个支持**英文、简体中文、繁体中文和中英混合内容**的智能体技能，适用于技术说明、操作流程、API 文档、需求和工程报告。它保留事实、不确定性、条件，以及“必须”“应当”“可以”“不得”等措辞的约束强度。

## 安装

把下面这段话发给你的编程智能体：

```text
请从 https://github.com/yfHHHE/ste-clarity 安装 ste-clarity 技能或插件。按照仓库的 AGENTS.md 和 INSTALL.md 操作，安装到我的用户级全局目录。
```

也可以按[安装指南（英文）](INSTALL.md)操作，选择 Codex、Claude Code 或其他支持技能的智能体。

安装后，在 Codex 中使用 `$ste-clarity`，在 Claude Code 中使用 `/ste-clarity:ste-clarity`。

## 改写前后

**原文**

> 当出现验证未能成功的情况时，接口应该尽快向调用方提供能够帮助其理解失败原因的相关信息。

**改写**

> 验证失败时，接口应该尽快向调用方提供说明失败原因的信息。

改写保留了“应该”和“尽快”，没有把建议改成强制要求，也没有编造响应时限或返回字段。参见[中文与双语示例](skills/ste-clarity/examples/chinese.md)和[英文示例](skills/ste-clarity/examples/before-after.md)。

## 三种模式

- **STE-80：** 默认模式，在保留原意的前提下改善表达，让技术内容更容易理解。
- **严格审阅（仅限英文）：** 根据指定的官方标准和适用术语进行有来源依据的审阅，并明确尚未验证的内容。
- **仅检查问题：** 找出重要问题，不重写全文。

可以这样使用：

```text
使用 $ste-clarity 改写下面的中文，保留原意，不补充未知事实。
请只检查这段需求中的歧义，不要重写。
请审阅这个操作流程，指出缺失的条件，不要自行补充。
```

## 中文与中英混合内容

技能会保留“必须 / 应当 / 可以 / 不得”的约束强度，以及“预计 / 暂未 / 基本”等限定语，不会为了简短而把不确定的信息写成确定事实。

**原文：** 目前核心功能基本完成，预计周五完成联调，暂未发现阻塞问题。

**改写：** 核心功能目前基本完成。预计周五完成联调。暂未发现阻塞问题。

未指定输出语言时，改写保留原文语言及简繁体。中文指令不会自动触发翻译。API 名、字段名和已有技术术语也不会被随意翻译。

例如：

```text
请改写这段英文，保留英文；用中文说明仍需确认的问题。
```

中文清晰度审阅不属于 ASD-STE100 合规审阅。具体规则见[中文写作指南](skills/ste-clarity/references/chinese.md)。

## 它会保护哪些信息

1. 事实、数字、单位、标识符和执行顺序。
2. 义务、许可、禁止和不确定性。
3. 条件、例外和性能要求。
4. 未知主体和缺失信息：明确指出，不自行猜测。
5. 原意完整性：必须先通过检查，才能进行清晰度评分。

技能只作用于当前请求的内容，不会永久改变整个对话的风格。兼容的智能体可以在相关写作任务中自动选择它，也可以由你明确调用。

## 关于 STE-80

STE-80 是一种实用写作风格的名称，**不是“达到 80% 合规”的评分**。该技能受 ASD-STE100 简化技术英语启发，并参考第 9 版。正式审阅需要查阅适用的官方版本及组织术语规范。

本项目与 ASD 或 STEMG 无隶属关系，也未获得其背书或认证。项目不分发官方标准，不提供合规认证。参见 [ASD-STE100 官方网站](https://www.asd-ste100.org/)。

## 仓库结构

- [核心技能](skills/ste-clarity/SKILL.md)：指令和模式选择。
- [内容指南](skills/ste-clarity/references/ste80-rules.md)：流程、需求、API 和报告的写作指导。
- [审阅量表](skills/ste-clarity/references/review-checklist.md)：原意完整性检查和清晰度评分。
- [智能体指南](AGENTS.md)与[贡献指南](CONTRIBUTING.md)：维护规则和检查步骤。

Codex 和 Claude 插件使用同一份核心技能。检查脚本会确认 Cursor 副本与核心技能完全一致。技能本身不包含运行时钩子、网络调用或可执行安装脚本。

## 验证

在仓库根目录运行：

```bash
python3 scripts/check_package.py
```

该命令检查包的一致性和文档内部链接，不能证明模型行为正确或符合正式 STE 标准。

参见[行为评估用例](evals/README.md)。[中文支持评估记录](evals/2026-10-07-chinese-evaluation.md)中的 10 个中文或双语用例及 3 个英文回归用例，在一次人工模型评估中通过；这不代表所有模型或平台都已验证。
