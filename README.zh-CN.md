# STE Clarity

[English](README.md) | 简体中文

**让 AI 的回答更清楚、更容易理解，同时保留原意。**

这是一个需要明确启用的回答风格技能，适用于日常问答、解释、建议、计划、比较和写作，不仅限于技术文档。支持英文、简体中文、繁体中文和中英混合对话。

启用一次后，持续作用于本次对话，直到你关闭。

## 安装与启用

把下面这段话发给你的编程智能体：

```text
请从 https://github.com/yfHHHE/ste-clarity 安装 ste-clarity 技能或插件。按照 AGENTS.md 和 INSTALL.md 操作，安装到我的用户级全局目录。
```

安装后，明确启用：

- **Codex：** `$ste-clarity`
- **Claude Code：** `/ste-clarity:ste-clarity`
- **直接请求：** “启用 STE Clarity，直到我说关闭。”

仅安装不会启用。说 **“关闭清晰模式”** 或 **“stop clarity mode”** 即可关闭；再次调用可以重新启用。安装和更新步骤见[安装指南](INSTALL.md)。

## 回答会怎样变化

1. **先回应问题。** 先给用户需要的答案，不堆开场白。
2. **更容易跟上。** 用具体、自然的语言，说明各个观点之间的关系。
3. **按问题组织。** 操作用步骤，选择用比较。简单问题可以只回答一句。
4. **保留必要深度。** 不删掉重要细节、不同选项或用户要求的解释。清楚不等于越短越好。
5. **保留事实与不确定性。** 区分事实、假设和建议，不为了显得具体而编造信息。

不强制标题、字数限制或每次结尾都给一个行动。安慰可以有温度，创作可以有趣。用户临时要求诗歌或详细解释，不会关闭整个对话的清晰模式。

## 日常使用示例

**用户：** 我只有 20 分钟整理房间，应该先做什么？

**回答：**

> 先整理地面，让自己能方便走动。可以按这个 20 分钟计划来做：
>
> 1. 用 5 分钟收集垃圾和餐具。
> 2. 用 10 分钟把散放的物品归位，从地面开始。
> 3. 用 5 分钟清理一个常用台面。
>
> 时间到了还没做完，就把剩下的区域留到下一次。

这里的时间分配是建议，不是假定知道房间情况或保证完成。更多例子见[一般对话示例](skills/ste-clarity/examples/conversation.md)。

## 中文与中英混合

保留“必须 / 应当 / 可以 / 不得”的约束强度，以及“预计 / 暂未 / 基本”等限定语。不会为了简短，把不确定信息写成确定事实。

**原文：** 核心功能基本完成，预计周五完成联调，暂未发现阻塞问题。

**改写：** 核心功能基本完成。预计周五完成联调。暂未发现阻塞问题。

一般回答默认跟随用户语言；改写默认保留原文语言和简繁体。用中文要求改写英文，不代表要求翻译。标识符和已有术语不随意改名。

参见[中文表达指南](skills/ste-clarity/references/chinese.md)和[中文与双语示例](skills/ste-clarity/examples/chinese.md)。

## 启用范围与持续性

明确启用后，即使换话题，也会持续应用于本次对话。新对话默认不启用。直接说“关闭清晰模式”“恢复普通模式”或“normal mode”会关闭；引文中的关闭指令不会改变状态。例如，要求翻译“stop clarity mode”不等于要求关闭。

持续性依靠对话中的指令，不是运行时钩子。如果宿主丢弃上下文，可能需要重新调用。不同智能体对调用元数据的支持不同，应在实际使用的平台验证。技能不会修改全局用户规则。

## 仍支持专业写作

用户需要时，也可以用于流程、需求、API 文档和报告的改写、翻译或审阅。转换内容时保留事实、主体、数量、条件和约束强度，缺失信息会指出而不是猜测。用户请求的新建议、计划和创意仍然可以生成，并明确它们是建议或设想。

- [技术内容指南](skills/ste-clarity/references/ste80-rules.md)
- [技术改写示例](skills/ste-clarity/examples/before-after.md)
- [审阅量表](skills/ste-clarity/references/review-checklist.md)
- [严格 STE 审阅指南](skills/ste-clarity/references/strict-review.md)

STE-80 是实用清晰表达方式的名称，不代表“80% 合规”。正式 ASD-STE100 审阅针对英文，需要查阅适用的官方标准和组织术语。中文清晰度审阅不能证明 STE 合规。

本项目受 ASD-STE100 启发，但与 ASD/STEMG 无隶属关系，未获其背书或认证，不分发官方标准，也不提供合规认证。参见[官方网站](https://www.asd-ste100.org/)。
